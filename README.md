# Sales Data Analysis | Power BI

## Project Overview
This project is a hands-on Power BI practice project completed while learning data analytics through Krish Naik's Data Analyst course.

The project focuses on exploring sales performance using interactive Power BI reports and visualizations. It provides views for reviewing sales, profit, quantity trends, and top/bottom 5 analysis.

## Tools Used
- Microsoft Power BI
- Data visualization and reporting

## Report Pages
1. **Overview** – Main report overview.
2. **Sales, Profit, Quantity by Period** – Analysis of sales, profit, and quantity across periods.
3. **Top/Bottom 5 Analysis** – Report page for comparing top- and bottom-performing items.
4. **Filter data** – Additional page included in the report.

## Key Learning Outcomes
- Practiced building a multi-page Power BI report.
- Gained hands-on experience with data visualization and report layout.
- Practiced presenting sales-related information through interactive report pages.
- Improved familiarity with Power BI reporting and analysis workflows.

## Project File
The `.pbix` file contains the Power BI report and can be opened using Microsoft Power BI Desktop.

## How to View the Project
1. Download or clone this repository.
2. Open `Sales Data Analysis.pbix` using Power BI Desktop.
3. Interact with the report pages and available filters.
